# Crear un proyecto 
- denominado:web-tunombre (Ejemplo: web-javier)
## Esta proyecto deberá contener las siguientes carpetas: 
- js, 
- css, 
- images, 
- test
## También los siguientes archivos: 
- README.md, 
- .gitignore
## El archivo README.md deberá mostrar información sobre la tarea a realizar
- El archivo .gitignore omitirá todo el contenido de la carpeta test
## Construir un sitio Web de un tema libre. 
- Ejemplo: deportes, películas, música, etc. 
- Se permitirá la generación de CSS utilizando herramientas basadas en IA
- La Web deberá construir utilizando HTML semántico head, main, nav, footer. 
## En este proyecto debemos considerar: 
- imágenes, 
- tablas, 
-enlaces, 
- formularios y footer con contacto para redes sociales.
## Todo el contenido estará dentro del archivo 
- index.html (raíz del proyecto). 
## Crear un archivo de estilos
- guardarlo en la carpeta CSS
## lo mismo crear un archivo de funciones 
- y almacenar en la carpeta JS
## El proyecto deberá contener 
- como mínimo 5 commit antes de subir a GITHUB
